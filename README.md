# Assignment #6 — jQuery

This project implements all tasks from Assignment #6: jQuery (Selectors, Effects, Animations).

## Tasks
- Task 0: jQuery CDN, document ready, console test
- Task 1: Selectors and CSS
- Tasks 2–4: Visibility, Fade, Slide effects
- Tasks 5–7: DOM manipulation, attributes, form interaction
- Tasks 8–10: Basic, sequential and combined animations
- Task 11: Interactive Image Gallery mini project

## Run
Open `index.html` in a browser. Internet access is required for the jQuery CDN and gallery images.

## GitHub Pages
Create a GitHub repository, upload all files, then enable **Settings → Pages → Deploy from branch**. Use the generated GitHub Pages URL for submission.

## Student information
Replace the Student and Group placeholders in `index.html` with your information.
